# 블로그오토 — 설치 파일 받는 곳

네이버 블로그 글을 주제에 맞게 쓰고, 이미지를 만들고, 예약 발행까지 해 주는 프로그램이에요.

## 처음 설치하기
1. 아래 **Releases → 최신 버전**에서 `BlogAuto_Setup.exe` 를 눌러 받아요.
   (크롬이 '흔하지 않은 파일'이라고 하면 [계속] / [유지]를 눌러요)
2. 받은 파일을 더블클릭 → 파란 경고 창이 뜨면 **[추가 정보] → [실행]**.
3. [확인]을 누르면 설치가 끝나고 블로그오토가 켜져요.

## 업데이트
한 번 설치하면 **새 버전이 나올 때 블로그오토가 스스로 업데이트**해요 (글을 쓰는 중이 아닐 때).
설정·키·로그인·쓴 글은 그대로 남아요. 화면 위 파란 줄에서 [자동 업데이트]를 끄고 직접 [지금 업데이트]를 누를 수도 있어요.
